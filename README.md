\# Neo *Avatar* Themed Rainmeter Suite



A Custom Rainmeter suite 



\## Included Skins

* **Audio Visualizer** : Vertical, symmetrical 64-band audio visualizer
* **Clock** : HH:MM:SS clock
* **System** : Displays CPU and RAM Usage
* **Network** : Displays name of network, upload and download speeds
* **Wall** : Image for depth effect



\## Installation

1\. Download the latest `.rmskin` package from the \[Releases page](../../releases).

2\. Double-click the downloaded file to install via Rainmeter.

3\. Your wallpaper is included inside the `@Resources` folder.
